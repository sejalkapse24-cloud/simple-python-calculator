# Simple Python Calculator

A small command-line calculator built with Python. It supports addition,
subtraction, multiplication, and division.

## Requirements
- Python 3.8 or newer
- No third-party packages required

## Run
```bash
python calculator.py
```

Enter the first number, choose `+`, `-`, `*`, or `/`, and enter the
second number. The program prints the result.

## Example
```text
=== Simple Python Calculator ===
Operations: +  -  *  /
Enter the first number: 12
Choose an operation (+, -, *, /): *
Enter the second number: 3
Result: 36
```

The program validates the operator and handles invalid numeric input and
division by zero.
